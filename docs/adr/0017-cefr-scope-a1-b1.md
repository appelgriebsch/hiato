# ADR 0017: CEFR pack scope v1 — A1–B1

- Status: Accepted
- Date: 2026-09-19
- Deciders: Andreas Gerlach

## Context
Full A1–C2 packs increase curation and download cost.

## Decision
Ship A1, A2, and B1 packs for EN/PT/DE/ES in v1. Defer B2–C2.

## Consequences
- UI CEFR picker limited to A1–B1 until later ADR.
- Pack pipeline still versioned for future levels.
