# ADR 0019: G0 UX Uma acceptance criteria

- Status: Accepted
- Date: 2026-09-19
- Deciders: Andreas Gerlach

## Context
Prototype must gate implementation (ADR 0010).

## Decision
G0 is accepted when a clickable mobile prototype covers: onboarding → language/CEFR select → daily play → result → share mock. Visual polish/motion can wait for T6.

## Consequences
- Low-fi wireframes alone are not enough.
- Full motion/skin approval is not required before Ivy starts T1–T5 against the accepted flows.
