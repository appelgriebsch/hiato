# ADR 0010: UX — prototype before implementation

- Status: Accepted
- Date: 2026-09-19
- Deciders: Andreas Gerlach

## Context
Product goal includes “fun and addictive”; greenfield UI risk is high.

## Decision
UX Uma produces a progressive mobile-first clickable prototype (shadcn) before Impl Ivy codes the production app.

## Consequences
- Critical path: design → approve → implement.
- Implementation plan and tracers assume Uma outputs as UX source of truth.
